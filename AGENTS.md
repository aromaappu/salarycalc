# Project Instructions

## Project
- This is a production project.

## Coding Rules
- Fix bugs only.
- Do not change the UI unless requested.
- Do not rename files or folders.
- Keep existing functionality working.
- Use the existing coding style.
- Do not add unnecessary libraries.
- Do not remove comments unless obsolete.
- Preserve backward compatibility.

## Debugging
- Check console errors.
- Check runtime errors.
- Check syntax errors.
- Check null and undefined errors.
- Check performance issues.
- Verify localStorage/database operations.

## Before Editing
- Explain the root cause.
- Show which files will be modified.

## After Editing
- List all changed files.
- Explain every change.
- Suggest improvements only after fixing the bug.

## Safety
- Never delete files unless requested.
- Never expose secrets or API keys.
- Ask before making breaking changes.
